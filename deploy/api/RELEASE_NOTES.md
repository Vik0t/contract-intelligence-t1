Серверный комплект для Linux x86_64 с обработкой договоров через DeepCode и модель `qwen3.8-flash-next`.

В архиве: backend с OCR и LibreOffice, frontend Nginx, PostgreSQL 16, Compose, шаблон окружения, исходники, идентификаторы образов и SHA-256. API-ключи и пользовательские документы не включены.

Реальная локальная проверка прошла на синтетических PDF, DOCX и JPG: 11/11 проверок полей, сводка, два контрольных риска, просмотр оригинала, выделение источников, подтверждение и редактирование результата. Протокол — `live-validation-2026-11-20.json`. Это проверка работоспособности, а не оценка качества на реальных договорах.

Исправлена проверка развертывания при автоматическом запуске извлечения: она принимает уже обработанный документ и учитывает одновременный запуск фонового задания.

После распаковки: `./load-images.sh`, `./init-env.sh`, заполнить `OPENAI_API_KEY` в `.env.server`, затем `./compose.sh up -d --no-build --pull never --wait` и `./check-api.sh`. Подробности — `README.txt` внутри архива.
