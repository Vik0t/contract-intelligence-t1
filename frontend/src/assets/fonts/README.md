# ALS Hauss — источник файлов

В интерфейсе используются Regular (400) и Medium (500), те же WOFF2-файлы, которые подключает официальный сайт https://t1.ru/. Проверено 28 октября 2026 года.

- https://t1.ru/media-files/disclabs/design-systems/als_hauss_regular.woff2
- https://t1.ru/media-files/disclabs/design-systems/als_hauss_medium.woff2

Файлы подключены локально через `src/index.css`: приложению не требуется обращаться к сайту Т1 для загрузки шрифта.
