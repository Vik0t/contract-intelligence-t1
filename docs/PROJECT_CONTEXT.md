## Что требуется сдать

Веб-сервис для загрузки договоров PDF/DOCX с текстовым слоем и ведения табличного реестра. Четыре обязательных атрибута: номер, дата, обе стороны с исходными и сопоставленными ролями, общая сумма с явно указанной валютой. Каждое поле сопровождают статус, причина сомнения, источник, страница или абзац и способ получения. Пользователь работает со своими документами; пакет, повторная обработка, просмотр оригинала и удаление входят в основной сценарий.

ПМИ требует долю простых договоров со всеми четырьмя правильными атрибутами ≥80 % и precision каждого атрибута ≥95 %. Recall и результаты нетиповых форм фиксируются отдельно. Оценка выполняется на заранее выделенной части синтетического набора с вручную проверенными эталонами. Один договор в PDF и DOCX остаётся в одной части набора.

Ограничения: до 10 с на договор без LLM, до 45 с с LLM, до 3 с на отклик реестра со 100 документами, восстановление до 120 с. Для обработки указан объём до 20 страниц. OCR, качество фотографий, вид договора, ИНН, сроки, НДС, сводки и риски — дополнительные возможности; их нельзя делать обязательными условиями приёмки четырёх атрибутов. Ошибка дополнительной функции становится блокером, если нарушает основной сценарий или искажает обязательный атрибут.

## Реализация

| Часть | Состояние |
|---|---|
| Интерфейс | React/Vite; таблица реестра, поиск, серверная сортировка, пакетная загрузка, карточка и оригинал, цитаты с подсветкой, исправление и подтверждение полей, JSON. |
| API и хранение | FastAPI, SQLAlchemy, SQLite при разработке / PostgreSQL в Compose; владельцы документов, сессии с bcrypt, исходные файлы, текст/DocumentIR, метаданные и очередь. |
| Проверки | Дата относительно загрузки, положительная сумма, различие сторон, подтверждение источником, конфликтующие кандидаты, явная валюта, восстановление очереди и понятный ответ при отказе БД. |
| `rules` | Закреплённая поставка [pmi-rules-v1](DELIVERY_PROFILE.md): CPU, четыре атрибута, нативный DOCX, текстовый PDF, OCR и внешняя передача выключены, PostgreSQL, автоматическая очередь. Настройки проверяются при старте и доступны через `/runtime/profile`. |
| `local` | NuExtract3; MLX на Mac или Transformers в серверном профиле. Серверный Compose использует PDF LibreOffice для DOCX. |
| `api` | Qwen через DeepCode; дополнительная проверка пропусков и связывание сторон с ИНН по источнику. Внешняя обработка требует соответствующей настройки и согласованного состава данных. |
