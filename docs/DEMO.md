# Подготовка и сценарий демонстрации

## Запуск

Выберите локальный профиль с GPU или DeepCode API по [инструкции развёртывания](DEPLOYMENT.md).
В API-профиле:

```bash
docker compose --env-file .env.api -f compose.yaml -f compose.api.yaml up -d --wait
curl --fail http://127.0.0.1:8080/api/health/ready
docker compose --env-file .env.api -f compose.yaml -f compose.api.yaml \
  --profile validation run --rm ml-check
python -m scripts.check_deployment --url http://127.0.0.1:8080 \
  --output tmp/deployment-check.json --session-file tmp/demo-session.json
```

`check_deployment` создаёт отдельную учётную запись и три синтетических договора.
Учётные данные для ручной проверки сохраняются в `tmp/demo-session.json` с доступом
только владельцу. Этот файл, ключи и отчёты с содержимым документов не входят в Git.

## Показ продукта

1. Открыть библиотеку: превью, имя файла, статус проверки, поиск и папки.
2. Загрузить PDF, DOCX или фотографию. Показать принятие файла и обработку без дополнительных настроек.
3. Открыть результат: исходный документ и извлечённые условия рядом.
4. Нажать «Показать в документе»: перейти к выделенной цитате.
5. Открыть «Кратко» и «Риски». Выбрать поставку или услуги, указать нашу сторону,
   подтвердить применимость обычного B2B-профиля РФ и нажать «Проверить договор».
   Показать цитату, связанные ограничения, рекомендацию и основание замечания.
6. Исправить значение, сохранить и подтвердить проверку оператором.
7. Скачать JSON, вернуться в библиотеку и открыть следующий документ.

## Результаты проверки

Точность полей, объём разметки и различия моделей описаны в
[отчёте сравнения](../evals/RESULTS_2026-10-27.md). Подтверждение оператором
сохраняется в базе; ручная правка возвращает документ на проверку и очищает
сводку и риски, рассчитанные по старым данным.

## Восстановление

Если анализ недоступен, сохранённые поля и оригиналы остаются доступны.
Повторите анализ кнопкой в документе и проверьте соединение с выбранным сервисом.
При перезапуске backend очередь восстанавливается из PostgreSQL.
Останавливайте стенд командой `docker compose ... down`, сохраняя volumes.
